# TTC 现在做到哪一步

更新于 2026-10-14。有些功能已经能跑，有些只是部分完成，我放在一起列清楚，免得首页几句话让人以为全部做完了。

| 功能 | 现在的情况 | 还要留意什么 |
| --- | --- | --- |
| 上传 Word 交底书 | 能提取 DOCX 正文和图片，限制文件大小并记录内容指纹 | 合成导入在部分回归里检查过 |
| 整理和确认技术方案 | 能逐项编辑、采纳、拒绝，确认后用于起草 | 方案 Agent 回归通过，专业质量还没做统一评测 |
| 起草权利要求 | 能生成、修订、校核，再由代理师确认 | 权要 Agent 回归通过，专业取舍仍需人看 |
| 附图和参考文字 | 按阶段任务生成，保留版本 | 产物 Agent 和三阶段回归通过 |
| 电学附图 | 支持可编辑的 Draw.io 图和预览 | 用合成材料检查过，浏览器预览也看过 |
| 机械附图 | 目前有图列表和标记建议 | 完整机械图还没做出来 |
| 说明书 | 能生成、保存历史，并核对上游输入 | 三阶段回归通过，正文仍需专业审核 |
| 撰写讨论和局部修改 | 可以按版本讨论，预览建议后再应用 | 整理作品集时查看了实现，没有重跑专项测试 |
| 确认版本 | 确认内容单独保存，带时间和内容指纹 | 相关快照和三阶段场景检查过 |
| 前面改动后的处理 | 跟踪材料、方案、权要和图的变化，标记受影响的结果 | 工作台和三阶段回归覆盖 |
| 失败时保留草稿 | 新任务检查通过后才切换当前稿 | Agent 和三阶段回归检查过失败保留 |
| 模型接入和取消 | 原生 HTTP 接入，支持流式输出和取消 | 模型接口回归通过 |
| 图片理解 | 已接视觉渠道，可选人工或自动确认，默认自动 | 这次没有评测真实识图效果 |
| 账号和案件 | 个人账号之间隔离，有管理员权限 | 账号隔离回归通过，还没有组织协作 |
| 用量和任务记录 | 保存每次调用，已知和未知用量分开记 | Agent 回归检查过失败计额 |
| 后台修改专业规则 | 可以编辑、覆盖和查看历史版本 | 查看了实际路径，没有重跑专项测试 |
| 最终稿和 Word 导出 | 组装、补齐、确认及导出有代码路径，后端已有测试 | 整体仍在开发、补验，完整浏览器流程尚未验完 |
| 整件案卷导出 | 后台有 ZIP 导出、清单和清理处理 | 查看了实现，没有重跑专项测试 |
| 多进程和横向扩展 | 当前使用应用进程和 SQLite | 还没有分布式队列，也没做规模验证 |
| 专业质量和节省时间 | 做过具体材料的本地模型试验 | 还没有可靠的整体合格率、节时数据 |
| 公共体验账号 | 邀请制内测 | 暂时没有自助登录账号 |

这里的进度以本地实现和已有记录为依据，内测服务器可能还没部署到同一版。具体跑过哪些测试，见[验证记录](VALIDATION.md)。
