# 看一遍 TTC 的界面

这几张图是在实际应用里截的。公开展示用的材料、确认状态和生成内容是单独预置的，模型也用了模拟响应，没有放客户案件。所以这里主要看操作和版本怎么衔接，真实模型的生成质量需要另看。

## 打开案件

工作台能看到案件和当前进度，点进去接着上次的内容做。

![案件工作台](../assets/screenshots/workbench.jpg)

## 看 AI 整理的方案

技术问题、方案和效果放在一起，可以逐项改、采纳或拒绝。确认以后，后面起草才用这些内容。截图里的测试方案很简单，是输入模块和输出模块的连接。

![方案编辑与采纳](../assets/screenshots/solution-review.jpg)

## 修改权利要求

当前稿、模型选择和撰写讨论分开显示。可以先讨论哪里要改，普通讨论不会直接改掉正文，处理好以后再确认。

![权利要求编辑与确认](../assets/screenshots/claims.jpg)

## 核对附图

这个电学例子有可以编辑的图源，能看对象、连接关系和对应权项。测试里预置的这份图没有校验报告，页面也会显示这个提示。

![附图预览与版本](../assets/screenshots/drawings.jpg)

机械方向目前主要提供图列表和标记建议，完整机械图还没做出来。

## 回看旧稿

历史里保留模型原稿和确认稿。选旧稿可以查看，要载入当前文稿，还需要明确操作。

![权利要求版本历史](../assets/screenshots/versions.jpg)
