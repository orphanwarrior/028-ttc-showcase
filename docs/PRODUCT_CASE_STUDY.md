# 做 TTC 的这两个月

TTC 是我自己在做的 AI 专利撰写工具。这两个月一直在改，上传交底书、提炼方案、写权利要求、准备附图和说明书，这些功能已经有了。需求、流程和开发迭代由我主导，实现中用了 Codex 等 AI 编程工具；一位行业经验更丰富的伙伴参与专业撰写规则的测试和优化。

我有专利代理的工作经验，所以做这个项目时，比较在意稿子拿到手以后到底能不能用。有些内容读起来很顺，术语也没错，但按实际撰写的要求去看，还是得大改。尤其是权利要求书，花在这上面的时间比我原先预想的多。

权利要求书可以理解为一份专利准备保护什么、保护到什么程度的文字。写得详细不一定写得好。比如材料里介绍了一整套设备，其中有些结构负责实现主要功能，有些只是安装、调节或者某种具体选型。主要的权利要求里放哪些、后面再补充哪些，需要作取舍。把材料里的东西全部搬进去，文字看起来完整了，保护范围却可能被自己写窄。

TTC 最早是用固定工作流处理这些问题的：先生成，再检查，把问题反馈回去修改。我当时希望把检查规则写清楚，让质量控制有一个比较稳定的过程。

后来发现，检查出来的问题很难都用同一种办法处理。缺了依据，需要回头查材料；保护重点没抓对，可能得重新组织整组权利要求；还有一些问题，看起来出在写作阶段，实际上前面的方案就提炼偏了。继续规定下一步必须做什么，越来越难照顾这些情况。

这时才开始考虑引入 Agent，让它能根据当前的问题决定要不要查材料、怎样修改，必要时回头处理。

但换成 Agent 也没一下子解决。早期把很多动作都交给模型决定，连提交草稿以后要不要检查、检查完要不要结束，都需要再问一次模型。过程拖得很长，材料和规则反复发送，有时候等了很久，还是没拿到能交给人看的结果。把调用额度往上加，也没有解决。

所以后来又往回收了一些。提交草稿后该做的基础检查，程序直接做；需要专业校核，就单独校核并修改。确实有问题，再留出回查的机会。材料缺了就问人，不能一直循环下去。

现在保留下来的，是一部分固定步骤，加上一部分有范围限制的自主处理。具体哪些交给模型，我还在随着试验调整。

## 有一阵子，检查报告比稿子更像那么回事

这也是做的过程中遇到的一个问题。

稿子里的取舍不理想，我就尝试让审核更细：某个特征为什么放在这里，为什么不能删，逐项写出理由。想着有了这些理由，至少能看出它是怎么判断的。

实际试下来，它确实能写出一大段解释，但正文里原先不合适的内容还在。审核甚至会顺着原稿，解释为什么这些细节都需要保留。表格填满了，解释也有了，我看稿子时觉得不对的地方，并没有因此解决。

后来就撤掉了部分逐句解释的要求。校核时也不直接把起草者的规划理由传过去，让它重新看交底材料，再判断这份稿子。需要改的地方，直接落到正文里。

现在我会把报告和正文对着看。报告说修好了，就看对应那段到底改成了什么。实际生成中仍然有自动审核没发现、人工才能看出来的问题，所以最终确认还得由代理师来做。

另外一个绕了一些路的问题，是前面的方案表。

这张表原本是方便人确认方案的，可以编辑、采纳或者拒绝。我把内容分成核心和附加，后面写权利要求时，模型却容易照着这个分类写：核心条目放进主要权利要求，附加条目各写一条。

对人来说，确认一条内容，通常是确认这件事有依据、可以采用。它最后适合放在哪个位置，还得结合整篇来判断。模型却把表里的分类当成了写作安排。

这就会出现一个问题：材料里确实有这个安装结构，我也确认可以用，但并没有要求把它放进主要保护范围。到了下一步，它还是照着写进去了。

于是又改输入的组织方式，把确认的事实和原来的分类分开，让模型重新考虑整组权利要求怎么写。只改传递方式，效果仍然不理想。后面连方案提炼本身也一起调整，保留后续写作需要的实现细节和依据，再往下试，部分结果才有改善。

这件事花时间，是因为问题虽然在最终稿里显露出来，不能只盯着最后写稿的那一步改。

## 还有一些地方，我宁愿让人多看一眼

整个产品还是按方案、权利要求、附图、说明书往下走，中间保留人工确认。前面理解错了，后面写得越多，返工越多。我想让代理师在继续之前，有机会把方向纠正过来。

不过，也不能什么都停下来问人。自动检查会给出各种建议，有的缺少关键事实，确实没法继续；有的只是还可以写得更好。如果都要求先解决才能往下走，流程很容易卡住。这个区别也花了时间去调整。

已经改过的稿子要保留，新一轮生成失败不能把它覆盖掉。做演示时可以重新跑，实际工作里，上一版可能已经人工改了很久，丢掉就很难接受。

目前，TTC 的这些流程已经可以运行，通过公网邀请制内测。电学方向的图可以编辑，机械方向主要做到附图列表和标记对照建议，完整机械图还没做出来。Word 导出还在开发、补验中。本地的新改动也需要部署、核对以后，才会到内测版本里。

我做过模拟模型的流程测试，也用真实模型试过具体材料。流程能跑通，稿子仍然可能有专业问题。前面提到的几处调整，都还不能说已经稳定解决了。

接下来想固定一组材料反复看，记录哪些地方总要人工改，改完需要多久。现在还不能给出一个可信的整体提效比例。对我来说，先弄清楚它到底在哪些工作上帮得上忙，哪些地方还不放心，比较实际。
