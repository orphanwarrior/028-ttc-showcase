| 测试 | 结果 | 主要检查什么 |
| --- | --- | --- |
| 工作台流程 | 通过 | 前置条件、当前版本绑定、失效和采纳 |
| 技术方案 Agent | 通过 | 回查与修订、过期报告、保存、权限和计额 |

测试使用合成材料、隔离数据库及模拟模型，没有调用付费模型，也没有使用客户资料。

## 我没有把哪些内容算作通过

- 真实模型完成整件案件后的专业质量。
- 从生成到最终导出的完整浏览器流程及全部屏幕尺寸。
- 内测服务器是否已经部署了本地最新版本。
- 生产负载、高可用、备份恢复和分布式执行。
- 用户规模、时间节省或专利成稿质量指标。
- 所有历史测试和旧执行分支。

内测服务可以通过 HTTP 访问，只能说明地址可达。仓库里存在某个测试脚本，也不等于这次已经运行通过。
