# 我检查过哪些地方

更新于 2026-10-14。整理作品集时，我重新跑了下面七项回归。产品代码和测试脚本还在私有仓库，这里把范围写清楚。

| 回归 | 结果 | 检查的内容 |
| --- | --- | --- |
| 工作台流程 | 通过 | 前置条件、当前版本、失效处理和方案采纳 |
| 技术方案 Agent | 通过 | 回查、修订、过期报告、保存、权限和计额 |
| 权要 Agent | 通过 | 调用限制、校核权限、失败保留和接口行为 |
| 产物 Agent | 通过 | 附图结构、修复、版本绑定、取消和用量 |
| 三阶段衔接 | 通过 | 合成场景 A–M，以及数据库外键 |
| 账号隔离和最终稿后端 | 通过 | 不同账号、图片确认、最终稿快照与导出相关处理 |
| 大模型 HTTP 接口 | 通过 | 流式输出、完成信号、异常和重复提交控制 |

这七项用的是合成材料、隔离数据库和模拟模型，没有调用付费模型。主要检查的是系统遇到这些情况时会怎么处理。

此前开发中也做过本地真实模型试验。[产品设计记录](PRODUCT_CASE_STUDY.md)里提到的几次调整，就有这些试验的依据。但具体材料上有改善，还不足以说明换一批材料也能稳定写好。

## 界面看过哪些

TTC 的五张截图在单独的测试环境采集，查看过页面切换、方案字段、权利要求、附图预览和版本选择。状态和内容是预置的，没有通过这次截图重跑一次完整的模型生成。

考试项目在独立本地会话里检查过十题练习、提交反馈、收藏、错题和刷新后的保存，也截了一张练习图。当前实际加载的三个题库分别有 26、24、26 题，共 76 题。

这次改介绍文字时，也整理了考试页面的说明：解析来自题库，“提问笔记”介绍的是网页之外的用法。题干、答案和解析没有做文风改写；练习逻辑只涉及显示文案的替换。

这次改完后检查了公开文档的相对链接和敏感信息模式，四张 Mermaid 图通过语法检查，也在本地浏览器里渲染过。考试页面重新试了十题练习、提交和解析显示，并查看了新的提问说明。这些检查只针对选出来的公开文件。

## 还没验证完的

Word 导出的完整浏览器操作还没验完，整体继续按开发中标注。真实模型跑完整件案件后的专业质量、代理师需要修改多少、到底省多少时间，也还缺一组固定材料和一致的评价标准。

手机和平板的全部页面、内测服务器是否部署到最新版本、生产负载、备份恢复和分布式执行，都没有在这次整理中完整验证。

这次是改作品介绍和页面文案，没有重新运行私有产品的全部历史测试。
